# Vrinda Store Annual Report 2022

## 📊 Project Overview

This project is an **Excel-based Sales Analysis Dashboard** created using the Vrinda Store 2022 sales dataset. The dashboard provides an interactive view of sales performance, orders, customers, order status, sales channels, categories, and state-wise sales.

The main objective of this project is to analyze the store's sales data and identify important business trends and insights.

## 🛠️ Tools & Techniques Used

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization
* Excel Dashboard

## 📈 Dashboard Analysis

The dashboard analyzes:

* **Monthly Order vs Sales**
* **Order Status** – Delivered, Cancelled, Refunded and Returned
* **Top 5 States by Sales**
* **Sales by Gender**
* **Orders by Age Group and Gender**
* **Orders by Sales Channel**
* **Sales by Product Category**
* **Month-wise filtering**
* **Channel and Category filtering**

## 🔍 Key Insights

* **Women customers contributed around 64% of sales**, while men contributed around 36%.
* **Delivered orders accounted for around 92%** of orders.
* **Maharashtra** was the highest-performing state among the top 5 states shown.
* **Amazon** was the leading sales channel, contributing around **35%** of orders.
* **Myntra** and **Flipkart** were other major sales channels.
* The dashboard allows users to interactively filter the analysis by **month, channel, and category**.

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive dashboard that can help understand:

* Sales performance
* Customer purchasing patterns
* Best-performing states
* Popular sales channels
* Order status
* Gender and age-group trends

## 📷 Dashboard Preview

The Excel dashboard contains interactive charts, Pivot Charts, and Slicers for exploring the sales data dynamically.

## 💡 Conclusion

This project demonstrates how **Microsoft Excel can be used for data cleaning, analysis, visualization, and dashboard creation** to generate meaningful business insights from sales data.
